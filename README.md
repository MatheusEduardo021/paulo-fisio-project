# paulo-fisio-project
Site institucional desenvolvido para Paulo Cavalcante, com foco em exercícios e reabilitação de idosos. Projeto criado com auxílio do **OpenAI Codex**, utilizando Next.js, React, TypeScript e Tailwind CSS, priorizando acessibilidade, design minimalista, responsividade e experiência do usuário (UX/UI).


# Paulo Fisio Project

O **Paulo Fisio Project** é uma landing page desenvolvida para apresentar serviços de fisioterapia e exercícios físicos voltados ao público idoso. O projeto tem como objetivo promover saúde, mobilidade, qualidade de vida e envelhecimento ativo, por meio de uma apresentação visual intuitiva, acessível e acolhedora.

A página busca facilitar o acesso às informações sobre os serviços oferecidos, incentivando os idosos a cuidarem da saúde e manterem uma rotina mais ativa.
